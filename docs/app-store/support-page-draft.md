## Installation and configuration

1. Install the app and approve the requested Shopify permissions.
2. In App Home, choose the jersey product and map S, M, L, and XL variants.
3. Add each supported customization surcharge amount and its Shopify variant.
4. Save and wait for the “checkout enabled” confirmation.
5. Open the Theme Editor link, add the 3D jersey app block to a product template, and save the theme.

## Requirements

- Shopify Online Store 2.0 theme.
- USD store and checkout currency for the current release.
- Product variants for S, M, L, and XL.
- Separate variants for every supported customization surcharge amount.

## Common issues

- Configuration will not activate: confirm the selected variants still exist and are not duplicated.
- App block is not visible: confirm it was added to the correct product template and the theme was saved.
- Jersey cannot be added to cart: retry from the product page and contact support with the design ID if the issue continues.
- Production order is missing: confirm the Shopify test or live payment reached the paid state.
