# Local Production Handoff Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Converge the live Shopify launcher with Git and require current downloaded production files before a bottom-pattern design can enter the Shopify cart.

**Architecture:** Preserve the existing local-production deployment. Add a small pure receipt module that fingerprints the current design state and validates the references generated by **Save design**. `ConfiguratorPage` coordinates downloads, stores the receipt, and consumes it during cart navigation.

**Tech Stack:** React 19, Vitest, Testing Library, Shopify Liquid, Cloudflare Workers, Git worktrees.
