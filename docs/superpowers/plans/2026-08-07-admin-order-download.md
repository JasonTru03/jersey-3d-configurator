# 独立订单后台与安全下载实施计划

## 目标

在当前腾讯云单店服务器运行时上增加独立商家后台，让工作人员通过强密码登录后，按 Shopify 订单号、设计编号、状态和日期查找已关联订单，并下载对应生产 ZIP。磁盘对象路径继续保持私有，后台只通过鉴权接口读取文件。

完成标准：未登录请求不能读取订单或 ZIP；登录会话使用安全 Cookie；后台仅展示配置店铺中已关联 Shopify 订单的设计；下载前再次校验订单归属和文件存在性；下载行为写入审计表；异常状态和缺失文件有明确提示。

## 本批次范围

- 新增 `ADMIN_SHOP`、`ADMIN_PASSWORD_HASH` 和 `ADMIN_SESSION_SECRET` 私有配置。
- 新增基于 scrypt 的密码校验和 HMAC 签名、限时、HttpOnly 会话 Cookie。
- 新增独立 `/admin/` 页面、登录/退出接口、订单查询接口和 ZIP 下载接口。
- 查询默认只返回已经绑定 Shopify 订单的记录，并始终按 `ADMIN_SHOP` 限定店铺。
- 新增下载审计 migration；记录设计、店铺、时间和下载结果，不记录顾客隐私。
- 增加登录限流、输入长度限制、安全响应头和文件缺失处理。

## 本批次不做

- 不连接真实 Shopify、不开启 OAuth，也不创建 Shopify Admin Block。
- 不修改生产状态，不做批量下载或模型管理。
- 不改变 3D 定制器、加购、支付回调和现有生产文件格式。
- 不 push、部署或替换服务器容器，相关外部操作仍需用户单独确认。

## 验证标准

1. 密码哈希、错误密码、篡改 Cookie、过期 Cookie和会话店铺不一致均被拒绝。
2. 未登录列表/下载返回 401；登录限流生效；退出后 Cookie 失效。
3. 查询仅返回配置店铺中有订单关联的数据，搜索、状态、日期和分页边界正确。
4. 正常 ZIP 以原生产文件名流式下载；对象缺失返回明确错误并写审计。
5. SQLite migration、服务器专项测试、相邻订单链路、全量测试和构建全部通过。

## 回退点

- 以 `codex/tencent-server-storage` 的 `a35b919` 为稳定基线，新分支为 `codex/admin-order-download`。
- 回退应用时切回 `a35b919` 镜像并保留 `/opt/jersey-data`。
- 新增审计表是只增 migration；旧镜像会忽略该表，不需要删除数据库或 ZIP。
