# Secure Jersey Configurator 1.0.0 应用打开页收尾计划

## 目标

把已经跑通的开发 App 收尾为 `1.0.0`，让商家从 Shopify 后台打开 App 时进入正式控制台，而不是临时授权成功页。

## 第一阶段：入口与页面

- 已安装且授权完整的店铺从 `/auth` 建立短期安全会话后跳转 `/app`。
- `/app` 作为唯一商家控制台，显示版本、店铺连接状态、结账配置状态和核心操作入口。
- 保留现有商品及变体配置能力，不改变订单、支付、生产文件和 App Proxy 链路。
- 不引入新依赖，不要求自有域名，继续使用固定 `workers.dev` HTTPS 入口。

验证标准：OAuth 定向测试、商家页定向测试通过，页面不泄露访问令牌或密钥。

## 第二阶段：版本与回归

- 根项目版本和锁文件更新为 `1.0.0`。
- 执行全量测试与构建。
- 使用桌面和窄屏视口进行真实页面视觉验收。

验证标准：全量测试与构建通过，桌面和移动布局无溢出、主要操作可访问。

## 第三阶段：发布与记录

- 发布前在腾讯云保存完整源码备份和回滚镜像。
- 部署候选镜像并验证容器健康、固定公网入口和 Shopify 后台真实打开流程。
- 更新 1.0.0 发布记录与对话交接。

回退方式：恢复发布前源码并切回发布前镜像，强制重建 `jersey-server`，以容器 `healthy` 和 `/healthz` 200 为成功标准。

## 本次不做

- 不购买或绑定自有域名。
- 不更改 Shopify 商品、订单、库存或支付设置。
- 不修改已验证的购物车、结账、Webhook 和生产文件数据结构。
- 不提交或推送 Git，除非用户另行要求。

## 完成状态

- 2026-08-14：三个阶段均已完成。
- 腾讯云、Shopify Development App `1.0.0` 及 Shopify Admin 真实打开流程均已验收。
