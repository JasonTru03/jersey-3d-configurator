# 球衣贴花重做：基于真实网格的投影方案

日期：2026-07-15  
状态：已确认，待实施  
适用分支：`codex/interactive-jersey-editor`

## 背景与结论

现有 Artwork 编辑器把贴花渲染到固定的世界坐标锚点。球衣模型载入时会按包围盒自动缩放、居中，而固定锚点不会随实际网格变化，因此徽章会悬浮在球衣旁；当 8 个槽位用满时，预设按钮被静默禁用，也会表现为点击无反应。

本方案替换 `2026-07-14-decoration-surface-placement-design.md` 中的固定锚点渲染策略：所有新贴花与旧设计恢复后贴花都投影到实际球衣网格上，不再依赖猜测的场景坐标。

## 目标

- 徽章、条纹与上传图片紧贴当前加载的球衣网格，不悬浮、不穿帮。
- 点击并拖动贴花时，以射线与真实球衣网格的交点作为新的贴花位置。
- 保存的设计文件保留贴花在网格上的位置；重新打开后可恢复。
- 旧版 JSON（没有网格位置数据）仍可打开，并在模型准备好后自动迁移为真实网格位置。
- 明确显示 `已用 / 8` 槽位；达到上限后点击预设或上传入口必须给出可见提示，不再静默失效。

## 不做的事情

- 不新增服务器保存、购物车、Checkout、Shopify 嵌入页或支付逻辑。
- 不改动尺码、配色、面料、文字印花等非 Artwork 链路。
- 不引入新的 3D 框架或第三方贴花库；使用项目已有的 Three.js `DecalGeometry`。

## 数据模型

每个 Artwork 项目保留现有 `region`、`x`、`y`、`scale`、`rotation` 字段以兼容既有文件，并新增可序列化的 `placement`：

```json
{
  "region": "front",
  "x": 0,
  "y": 0,
  "scale": 1,
  "rotation": 0,
  "placement": {
    "region": "front",
    "position": { "x": 0.12, "y": 0.46, "z": 0.71 },
    "normal": { "x": 0.03, "y": 0.11, "z": 0.99 }
  }
}
```

- `placement.region` 记录该坐标对应的面；与当前 `region` 不一致时，说明用户切换了位置，必须重新计算默认贴花点。
- `position`、`normal` 使用模型在场景中的世界坐标，避免受模型自动缩放与居中影响。
- `scale` 与 `rotation` 继续控制贴花尺寸、绕法线旋转；它们不是世界坐标。

## 渲染与交互

1. `GarmentRenderer` 向 Artwork 编辑器提供当前实际可拾取的球衣网格。
2. Artwork 编辑器针对每个贴花，以 `DecalGeometry(mesh, position, orientation, size)` 创建投影几何体；投影位置使用 `placement`，法线决定朝向。
3. 新增预设或上传素材时，沿当前区域（前、后、左右袖）的方向从模型包围盒外向中心发射射线，取命中的真实网格交点作为默认 `placement`。
4. 用户拖动选中的贴花时，持续射线检测真实球衣网格，命中后更新 `placement.position` 与 `placement.normal` 并重建该贴花几何体。
5. 切换 Artwork 区域时，清除该项过期贴花位置，按新区域重新投影；不复用旧区域的坐标。
6. 贴花材质启用透明度、深度测试和 polygon offset，减少与球衣面重叠时的闪烁。每次重建都释放旧贴花几何体，避免长时间编辑造成内存增长。

## 兼容与失败处理

- 读取旧设计时，如果项目没有 `placement`，在球衣网格加载完成后按其 `region` 计算默认投影位置，并写回当前设计状态；之后保存即得到新格式。
- 若当前模型尚未完成加载或默认射线没有命中，不创建悬空替代物；界面显示“球衣模型尚未准备好，请稍后重试”。
- 如果拖动时未命中球衣网格，保留上一次有效位置，不更新为无效坐标。
- 导入校验继续遵循现有产品匹配与错误文件不覆盖当前设计的保护规则。

## 槽位反馈

- Artwork 面板展示 `N / 8 artwork slots used`。
- 达到 8 项时，预设卡片与上传入口仍可点击以给出统一提示：`You can add up to 8 artworks. Remove one to continue.`
- 现有删除动作保持可用，使用户可以立即腾出槽位；不自动删除或替换已有素材。

## 测试与验收

先补失败测试，再实现最小代码。至少覆盖：

- 默认区域射线得到的贴花位置来自实际球衣网格，而非固定场景常量。
- 拖动更新位置与法线；未命中时保持上一次有效贴花位置。
- 切换区域后会重新投影，旧区域位置不会复用。
- 旧版无 `placement` 的设计能得到有效位置；含 `placement` 的新设计往返保存不丢失。
- 第 8 个素材加入后显示 `8 / 8`；第 9 次点击会显示上限提示且不改变设计。
- `npm test` 与 `npm run build:showcase` 通过。
- 浏览器验收：前、后、左右袖添加预设，拖动贴花，保存并刷新后重新导入，以及移动端基础布局。确认徽章始终贴在可见球衣面上。

## 阶段与检查点

1. **网格贴花底座**：新增位置数据、网格拾取与 `DecalGeometry` 渲染，目标测试通过后提交并推送。
2. **编辑与兼容**：拖动、区域重投影、旧 JSON 自动迁移，目标测试通过后提交并推送。
3. **可用性与验收**：槽位提示、完整回归、变更和 Bug 日志，提交并推送；经用户确认后合入 `showcase` 触发 Cloudflare 部署。

## 风险与回退

`DecalGeometry` 在非常尖锐的衣物折角可能产生局部拉伸；本期以贴紧网格和稳定交互为优先，不将投影限制扩展为复杂 UV 编辑器。每个阶段在功能分支独立提交；若线上验收异常，可将 `showcase` 回退到当前稳定发布提交 `0735207`，不改写历史。
