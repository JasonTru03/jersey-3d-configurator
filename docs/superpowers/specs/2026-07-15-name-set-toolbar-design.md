# Name set 对象工具栏设计

## 目标

在独立 3D 定制器中，用户选择或点击一组 Name set 后，可在该印字周围看到对象控制框，并完成编辑、旋转、删除、复制、自由缩放与拖动移动。

## 范围

- 仅改独立定制器的印字体验。
- 不改 Shopify 嵌入页、购物车、结账或支付逻辑。
- 保留现有大小、配色、面料、Artwork 和本地设计文件功能。

## 交互

1. 点击可编辑的 Name set 后选中该印字，并显示红色轮廓与五个图标控件。
2. 编辑：打开已有 Print 面板并聚焦名称字段；号码仍在同一面板修改。
3. 旋转：每次点击沿球衣表面法线旋转 15°，循环保持在 0 至 345°。
4. 删除：移除当前选中的 Name set；最后一组被删除时，印字不显示，但不改动用户的其他商品选项。
5. 复制：新增独立的一组相同 Name set，在可见且未与既有印字重叠的默认位置生成，并选中新副本。
6. 缩放：拖动控制框右下角手柄自由缩放；限制在 55% 至 180%，防止印字过小或遮挡整个球衣。
7. 移动：保留已有拖动印字到球衣表面的方式。点击控件本身不会触发 3D 相机旋转或移动。

## 数据与兼容

- 新增 `overrides.printItems` 数组；每项包含稳定 `id`、`name`、`number`、`placement`、`scale` 与 `rotation`。
- 旧设计文件仍保留 `printName`、`printNumber`、`printPlacement`；加载时将其转换为第一项 `printItems`，不丢失旧用户设计。
- 新保存文件同时保留旧字段与第一项同步值，确保之前的读取路径可继续使用。
- 所有对象操作通过既有 `updateState` 进入不可变历史，支持撤销、重做、保存及重新导入。

## 渲染与界面边界

- `garmentRenderer` 负责将每个 `printItem` 渲染为独立平面、命中检测、基于球衣表面生成复制后的默认位置，以及把位置/缩放/旋转结果回传状态。
- 新的屏幕覆盖层组件负责绘制选中框和五个按钮；它只处理 DOM 控件与屏幕位置，不保存业务状态或直接改 Three.js 对象。
- `ConfiguratorPage` 保持 Print 表单的输入职责，并接收“编辑当前对象”的请求；页面组件不承担 3D 射线或转换计算。

## 错误与边界

- 当 Print 选项为 `None` 或没有印字时，不显示控制框。
- 重复点击复制最多创建 8 组；达到上限时按钮禁用并给出简短用户提示。
- 无法在球衣表面找到有效复制位置时，不新建对象并保持当前选择。
- 重新选择、删除、撤销、导入设计后，控制框必须跟随当前有效对象；不存在的对象不可保留为选中状态。

## 测试与验收

- 状态迁移：旧单组印字配置可加载为一项 `printItems`。
- 对象操作：复制生成不同 ID 与不同位置；旋转、缩放、删除及边界限制正确写入状态。
- UI：点击印字显示工具栏；五个控件分别触发预期状态；删除后工具栏关闭；撤销后恢复。
- 渲染：多组印字同时显示，拖动和缩放不会启用相机控制。
- 最终运行 `npm test`、`npm run build:showcase`，并在浏览器验证桌面与移动端工具栏不会遮挡 Print 表单。
