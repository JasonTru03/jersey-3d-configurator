# Name Set 贴边选中控件设计

日期：2026-07-16  
状态：已确认，待用户审阅书面规格  
范围：独立 3D 定制器中 `Name set` 的选中与直接编辑控件

## 目标

Name Set 未选中时，球衣上仅显示用户输入的名字文字；用户直接点击该文字后，才出现一圈紧贴文字的选中框及五个操作按钮。控件必须随文字的 3D 投影位置和尺寸移动，不得以固定的侧边面板遮挡球衣。

## 用户交互

1. 初始、取消选中或点击球衣空白区域时：文字正常显示；选中框和所有操作按钮都不渲染。
2. 用户点击可编辑的 Name Set 文字时：选中该项，并围绕该项的屏幕投影边界显示细边框。
3. 五个按钮固定在边框附近：左上“编辑”、右上“顺时针旋转”、左下“删除”、下中“复制（×2）”、右下“缩放”。按钮使用现有可访问标签；复制按钮视觉文案为 `×2`。
4. 拖动、旋转、缩放文字，或旋转 3D 球衣/相机时：选中框与五个按钮同步重新定位。
5. 复制后：新副本成为当前选中项，并立即显示其贴边控件。
6. 删除后：清除选中状态和控件；再次选择 `Name set` 时，仍可创建并编辑默认的 `PLAYER / 16`。

## 架构与数据流

### GarmentRenderer

- 将当前选中贴花平面四个角投影到舞台 DOM 坐标，而不是仅投影平面中心。
- 由独立纯函数计算 `{ left, top, width, height, visible }` 选中矩形；当平面在相机后方、完全离开舞台或尺寸无效时返回不可见。
- 只在选中矩形有实际变化时调用 `onPrintAnchorChange`，避免每帧触发 React 无效更新。
- 指针命中 Name Set 时通知 React 选中其 ID；点击未命中贴花的球衣/画布时通知 React 清除选择。

### ProductStage

- 区分“当前可编辑贴花 ID”和“用户正在选中的贴花 ID”。默认不显示控件。
- 仅当用户实际选中一个 Name Set，且渲染器提供可见选中矩形时，才渲染控件覆盖层。
- 删除、空白点击、切换为 `None` 都清除选中状态；复制时选中新副本。

### PrintToolbarOverlay

- 接收渲染器提供的选中矩形，绘制只读的边框与绝对定位按钮。
- 边框本身不拦截画布手势；只有按钮接受指针事件，避免影响球衣旋转与文字拖动。
- 控件仅服务 Name Set；普通 Artwork 不显示该工具框。

## 边界与错误处理

- 当文字很靠近舞台边缘时，控件可向内偏移，但选中边框仍严格围绕文字。
- 当文字不可见、被相机遮挡或投影尺寸异常时，覆盖层隐藏，不保留旧坐标。
- 删除最后一个 Name Set 后不留下悬浮控件，也不阻止后续重新添加。
- 不改变 Shopify 嵌入页、购物车、支付、服务器存储、Cloudflare 配置或贴花业务数量上限。
- 不新增第三方依赖。

## 测试与验收

1. 为投影矩形纯函数编写单元测试：正常矩形、画布外、相机后方与无效尺寸。
2. 为覆盖层编写组件测试：未选中不渲染；选中时边框和五个带标签的控件出现；`×2` 显示为复制操作。
3. 为舞台交互补测：点击文字选中、点击空白取消、删除后隐藏、复制后选中新副本，以及删除后可重新创建 Name Set。
4. 运行目标 Vitest 测试、完整 `npm test` 和 `npm run build:showcase`。
5. 在支持 WebGL 的浏览器手动验证：文字未选中无框；点击出现贴边框；拖动、旋转、缩放和球衣旋转时同步跟随；空白点击隐藏；桌面与移动端基础布局正常。

## 风险与回退

投影矩形依赖画布 DOM 尺寸、相机和设备像素比。实现会使用舞台的 CSS 像素尺寸，并对极小差异节流。如果视觉定位出现不可接受偏差，可回退本功能提交，恢复当前已发布的锚点工具栏行为。
