# Name Set 对象锚定工具栏设计

日期：2026-07-16  
状态：待用户确认  
范围：独立 3D 定制器的 `Name set` 个性化文字编辑

## 问题与目标

当前 Name Set 在删除唯一文字对象后，再次点击 `Name set` 只会切换选项，不能重新创建文字；同时，编辑工具栏固定在舞台中央，无法反映选中文字的实际位置。

本次目标：

- 删除最后一个 Name Set 后，重新选择 `Name set` 会创建默认 `PLAYER / 16` 并立即选中。
- 工具栏仅在已选中文字时显示，且显示在文字旁边。
- 文字拖动、旋转、缩放，或用户转动 3D 球衣／镜头时，工具栏实时跟随。
- 当工具栏接近画布右边或上边时，自动翻转到文字的左侧或下方，避免被裁切。

## 已选方案：真实对象锚定

渲染层从当前选中文字的 Three.js 平面取得世界坐标，并在渲染更新中投影为舞台容器坐标。React 工具栏接收该锚点并以绝对定位显示。

默认位置为文字右上方；若右侧空间不足则翻转为左上方；若上方空间不足则改为下方。工具栏使用现有五项操作：编辑、顺时针旋转、复制、删除、缩放。

此方案比只使用保存的贴花坐标更准确：在用户旋转球衣、拖动文字、缩放文字、调整相机时都不会偏移。

## 数据与组件边界

1. `printItems.js`
   - 增加一个小型纯函数，用于确保当前选择的 Print 类型在 `printItems` 为空时创建默认文字项目。
   - 保持 `printItems` 不可变更新以及旧版首项字段兼容。

2. `ConfiguratorPage.jsx`
   - 在用户选择 `Name set` 或 `Raised print` 时调用该纯函数。
   - `None` 不创建文字。

3. `garmentRenderer.js`
   - 为当前 `activePrintId` 输出投影后的工具栏锚点：`x`、`y`、`placement`、`visible`。
   - 仅在锚点有可见差异时触发回调，避免每帧造成 React 无效更新。
   - 删除、取消选择、文字不在相机前方或离开视口时，将锚点设为不可见。

4. `ProductStage.jsx`
   - 保存锚点 UI 状态并传递给工具栏。
   - 删除当前项目后清除活动 ID 和锚点，避免出现悬浮残影。

5. `PrintToolbarOverlay.jsx` 与 `configurator.css`
   - 根据锚点和翻转位置渲染；没有项目或不可见时不渲染。
   - 保留键盘标签和现有可访问名称。

## 边界与异常行为

- 用户删除最后一个 Name Set：工具栏消失；再次选择 `Name set` 创建默认文字并显示工具栏。
- 用户选择 `None`：不创建文字；现有文字按当前产品逻辑处理，工具栏不显示。
- 用户点击不同文字：工具栏立即切换到新文字。
- 文字靠右：工具栏放在左上；靠上：工具栏放在右下；两种情况同时发生时放在左下。
- 工具栏自身在舞台安全边距内钳制，不会被舞台裁切。
- 非 Name Set 的装饰贴花不显示本工具栏。

## 不做的内容

- 不改 Shopify 嵌入页、购物车、支付、服务器保存或 Cloudflare 配置。
- 不改变现有文字、贴花的尺寸数值或绘制算法。
- 不新增第三方依赖。

## 风险与回退

投影坐标会受到画布尺寸、设备像素比和相机状态影响。实现将统一使用舞台 DOM 尺寸而非渲染缓冲区尺寸，并以最小像素差节流。若出现定位偏差，可回退本次功能提交；原固定工具栏逻辑保留在 Git 历史中。
