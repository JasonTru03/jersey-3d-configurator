# Artwork 图案列表与无边框选择设计

日期：2026-07-17
状态：已确认，待用户审阅书面规格
适用分支：`codex/artwork-library`

## 背景与目标

已发布版本使用红色屏幕矩形表示选中的 Artwork。该矩形来自贴花 3D 外包盒，包含透明素材留白，无法准确贴合可见图案，且视觉上突兀。此前为支持选中后旋转球衣，空白点击不再取消 Artwork 选择，导致用户缺少直观的退出方式。

本次移除红色选择框。右侧 Artwork 面板提供最多 8 个已添加图案的缩略图列表，用户可直接在列表中选择或删除图案。画布上使用短暂、轻微的图案提亮/缩放反馈确认选择；空白单击取消选择，空白拖动继续旋转球衣且不取消选择。

## 用户可见行为

1. 点击球衣上的 Artwork 或右侧已添加图案缩略图时，图案成为当前选中项。
2. 选中 Artwork 时不显示任何红色、矩形或屏幕覆盖框；图案只做一次短暂的轻微提亮与缩放反馈，随后恢复正常渲染。
3. Artwork 面板在槽位计数下方显示“已添加图案”缩略图网格，按加入顺序最多显示 8 项。每项显示实际素材预览和简短标签；上传图片使用其 Data URL 预览。
4. 当前选中缩略图有明确但低干扰的面板高亮。点击任一缩略图会切换当前选中项，并同步画布反馈和已有旋转、缩放操作。
5. 每个缩略图右上角都有独立删除图标。点击该图标只删除对应 Artwork，不会触发缩略图选择；删除当前选中项后清除选中状态，删除其他项时保留当前选择。
6. 从 Artwork 本体开始拖动仍移动 Artwork；从图案外球衣区域开始拖动仍旋转球衣。
7. 图案外球衣区域的短按/单击取消 Artwork 选择；存在明显指针移动时视为旋转，不取消选择。
8. Name set 的选择框、五个控制按钮、点击/拖动逻辑不在本次范围内。

## 实现边界与数据流

### 右侧图案列表

- `DecorationPanel` 继续以 `state.overrides.decorations` 为唯一列表来源，以 `activeDecorationId` 表示当前选中项，不新增持久化字段。
- 新增聚焦的 `ArtworkLibrary` 组件，接收图案数组、活动 ID、选中和删除回调；其职责仅为缩略图渲染、缩略图选择和删除按钮事件隔离。
- 每项缩略图用现有 `resolveDecorationAsset` 得到图片 URL，以确保当前两枚预设、上传图片和旧设计中的 legacy pattern 都能预览。
- 删除通过现有 `removeDecoration` 完成；列表没有图案时不渲染空卡片或技术说明。

### 画布选择与取消

- 删除 `ArtworkSelectionOverlay`、`decorationAnchor` 与 Artwork 投影边界计算，不再生成或发送 Artwork 屏幕矩形。
- `DecorationEditor` 保持选择和拖动分离，但新增一个轻量、非持久的选择反馈状态：选中项的贴花材质在有限时长内提高亮度/不透明度并在当前模型表面做极小缩放脉冲；不改变保存数据、placement、rotation 或 scale。
- `GarmentRenderer` 为 Artwork 指针交互记录起点和移动距离。若指针未命中 Artwork：移动距离未超过现有拖动阈值时，调用 Artwork 取消选择；超过阈值时保持选择并让 OrbitControls 处理旋转。
- 点击 Artwork 或右侧缩略图时都经 `activeDecorationId` 同步到渲染器；右侧选择需要触发同样一次性的画布反馈。

## 错误处理与可访问性

- 资源预览加载失败时，缩略图仍保留可操作的标签和删除图标，不使用空白可点击元素；现有渲染器的图片加载错误处理保持不变。
- 缩略图按钮和删除按钮均使用图案标签生成可访问名称。删除按钮的事件必须阻止冒泡，避免删除时意外选中。
- 所有图案删除后，`activeDecorationId` 为 `null`，右侧旋转、缩放和删除动作隐藏；之后加入新图案可正常选中。
- 不改变 8 项槽位上限、上传类型/大小校验、保存/导入 JSON、Shopify、购物车、支付、服务器保存、Cloudflare 配置或既有 Name set 工具栏。

## 测试与验收

先写失败测试，再实现最小改动。至少覆盖：

1. Artwork 红框组件、投影回调和 CSS 不再由舞台渲染；Name set 工具栏仍在其原有条件下渲染。
2. 右侧列表按图案数组渲染预设、上传和 legacy 素材缩略图；活动项有状态；点击缩略图更新 `activeDecorationId`。
3. 每个删除图标仅删除对应项；删除活动项清空选择，删除非活动项保留活动选择；删除事件不触发缩略图选择。
4. 未移动的空白点击取消 Artwork 选择；超过阈值的空白拖动不取消选择且保持 OrbitControls；Artwork 本体拖动继续更新 placement。
5. 选择反馈不改变持久化的 `scale`、`rotation` 或 `placement`，且在动画结束后清理；缩略图选择和画布命中选择都会触发一次反馈。
6. 运行目标 Vitest 测试、完整 `npm test` 与 `npm run build:showcase`。在具备 WebGL 的浏览器手工确认：无红框、缩略图选中/删除正确、空白单击取消、空白拖动旋转、Artwork 拖动移动、窄屏仍可触达，Name set 不回归。

## 风险与回退

缩略图预览复用现有 Data URL 和预设资源，不增加文件上传或保存结构风险。选择反馈必须限制为材质/显示层的临时状态，避免将动画值写入设计 JSON。

本功能在独立分支中以可回退提交完成。若验收不符合预期，使用保留历史的 `git revert` 回退功能提交；未经用户确认，不合并、推送或发布。
