# 足球球衣模板与分区配色设计

日期：2026-07-21

状态：用户已确认，待审阅实施计划
适用分支：`codex/template-zone-design`

## 目标

为 3D 球衣定制器加入足球球衣模板与固定分区配色。用户可选择六种模板，并分别设置衣身主色、袖子、肩部/侧片、领口、模板图案和姓名号码颜色；修改应立即反映在 3D 模型上。

本期仅覆盖定制器前端与本地设计文件。Shopify 加购、购物车、Checkout、支付、云端草稿、分享、Roster 和人工审核不在范围内。

## 用户可见行为

1. 右侧配置面板新增 `Templates` 入口，提供六张足球球衣模板缩略图：纯色、竖条纹、横条纹、斜纹、渐变、拼色。
2. 选择模板会立即更新 3D 球衣外观，且不会重置用户已选颜色、Artwork、姓名号码或其他现有配置。
3. `Colors` 入口展示六个固定色区：衣身主色、袖子、肩部/侧片、领口、模板图案色、姓名号码色。
4. 选择色区后可从统一预设色板中选择颜色；首期不提供任意取色器，以保持印刷颜色可控。
5. 姓名号码颜色从 `colors.number` 读取，现有 Name set 的预览同步变化。
6. Undo / Redo、打开设计、保存设计与设计摘要保留，并记录模板与六色信息。
7. 窄屏中模板与配色项在同一个右侧面板内纵向排列；3D 画布、Artwork 操作和 Name set 工具栏继续可用。

## 数据模型与兼容性

在现有 `state` 中增加版本化的外观覆盖字段：

```js
overrides: {
  appearance: {
    textureVersion: 1,
    templateId: 'solid',
    colors: {
      body: '#F7F5EF',
      sleeves: '#F7F5EF',
      shoulderSide: '#20242A',
      collar: '#20242A',
      pattern: '#D8C17A',
      number: '#20242A',
    },
  },
}
```

- 旧设计未包含 `appearance` 时，以现有 `colorway` 的 swatch 映射生成默认外观；不会拒绝或覆盖旧设计。
- `textureVersion` 用于未来纹理生成规则变更时保持存档可读。
- `templateId` 和 `colors` 是可撤销状态的一部分；Artwork、打印内容和坐标数据维持原有结构。
- 现有 `colorway` 在本期变为初始配色来源和兼容字段，不再通过材质数组顺序决定最终衣服颜色。

## 渲染架构

### 纹理生成

- 使用模型可用 UV 创建一张 Canvas 设计纹理。
- 模板生成器接收 `templateId` 和六色对象，绘制对应的足球球衣平铺图案。
- 生成的 `CanvasTexture` 使用 sRGB 色彩空间，并替换或更新衣服可渲染网格的 base-color map。
- 每次更新复用或释放旧纹理，避免连续选色造成 GPU 纹理泄漏。
- Name set 继续使用独立的贴花层，但其颜色由 `appearance.colors.number` 驱动。

### UV 预检与回退

实施的第一个检查点是只读验证 `public/models/chelsea-jersey.glb`：

1. 衣身、前后面、袖子和领口网格必须有可用 UV；
2. 测试纹理必须能定位六个视觉区域；
3. 贴图更新不能影响 Artwork 的贴花曲面选择。

若模型的 UV 不支持统一且可辨识的分区纹理，本期停止在稳定版，不以材质数组索引或临时几何遮罩伪造分区；后续需替换为带明确区域 UV 的足球球衣模型。

## UI 架构

- 新增只负责模板列表的 `TemplateLibrary` 组件。
- 新增只负责色区选择和色板的 `ZoneColorPanel` 组件。
- 配置层提供模板元数据、预设色板和默认外观转换函数；UI 不直接依赖 Three.js。
- `ConfiguratorPage` 只负责选择入口与状态更新，`ProductStage` 保持渲染器桥接职责。
- `GarmentRenderer` 接收规范化后的外观数据，并委托纹理生成模块更新模型；不把模板逻辑堆入指针、Artwork 或 Print 交互代码。

## 错误处理

- 缺失、未知的模板 ID 回退为 `solid`，并保留其余颜色。
- 非法颜色值在导入设计时按现有设计文件校验规则拒绝本次导入，不能半写入当前设计。
- 纹理生成或模型 UV 校验失败时，保留上一次有效外观并在界面显示明确错误；不静默显示错误颜色。
- 在模型未完成加载、组件卸载或渲染器释放后，不再更新纹理。

## 验收与测试

### 自动化

- 配置层：六模板、六色默认值、旧 `colorway` 迁移、未知模板与非法颜色校验。
- UI：模板选择、色区选择、选中状态、模板切换不重置颜色，以及窄屏布局。
- 状态：模板与六色参与撤销/重做、保存与导入。
- 场景：纹理生成参数、纹理替换/释放、姓名号码色同步与模型未就绪边界。
- 回归：Artwork 添加/删除/拖动/镜头聚焦、Name set 选中与工具栏、Orbit 控制均保持可用。

### 人工验收

1. 依次选择六个模板，旋转模型检查前后面与袖子图案连贯；
2. 分别修改六个色区，确认只影响规定区域；
3. 修改姓名号码色，确认文字即时变化；
4. 选模板与配色后执行 Undo / Redo、保存、重新打开设计；
5. 添加、拖动 Artwork，编辑 Name set，并在桌面与窄屏检查布局。
