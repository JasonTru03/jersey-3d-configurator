# UV 裁片生产图设计

日期：2026-07-31  
基线：`0a0bd1c`（阶段二生产文件已发布）

## 目标

将当前生产 ZIP 中的单一 UV Atlas 扩展为两种用途明确的 PNG：

1. `uv-atlas.png`：严格按照 GLB 原始 UV 坐标输出，可重新贴回 3D 模型，用于系统和技术核对；
2. `uv-pattern-pieces.png`：从同一份真实 UV 数据提取裁片，统一方向、拆开并留间距，供工厂查看每个裁片上的完整图案。

裁片图不绘制尺寸线、缝份、放码线、纸样编号或其他无法从模型确认的生产数据。它是“模型 UV 裁片图”，不是 1:1 服装纸样。

## 已确认的根因

当前基础花型由 `garmentAppearanceTexture.js` 中的固定 `UV_REGIONS` 绘制；姓名、号码、文字和上传图案则由 `productionAtlasBaker.js` 投影到真实 GLB UV。两套坐标系统并不一致，因此导出的 PNG 不能同时作为可靠的基础花型图和模型 UV 图。

真实 GLB 的 UV 网格可以拆出多个独立岛，但其排布服务于 3D 贴图，存在旋转、镜像、重复内外表面和零散位置，不等同于工厂纸样排版。代码不能仅凭 `Cloth_mesh_数字` 可靠推断前片、后片、袖片和领片。

## 范围

### 包含

- 用真实模型 UV 三角形绘制基础颜色、渐变、色块和底纹；
- 保留现有外侧可见性、正背面隔离、图案投影和图层顺序；
- 为每个支持模型增加 UV 裁片清单；
- 去除重复内外面或重复 UV 岛的重复输出；
- 根据清单将 UV 裁片转正并重新排版；
- ZIP 增加 `uv-pattern-pieces.png`；
- PDF 第 2 页优先展示裁片排版图；
- Manifest 记录两张 PNG、裁片来源和方向；
- 增加模型级、图集级、生产包级回归测试。

### 不包含

- 不从 GLB 反推真实缝制纸样；
- 不生成尺寸、放码、缝份、裁片编号或工艺标注；
- 不修改 Shopify 结账、订单关联、R2 或后台模型上传；
- 不引入新的渲染框架或图像处理依赖；
- 不在没有裁片清单的模型上凭启发式猜测并生成工厂图。

## 设计

### 1. 模型 UV 裁片清单

在配置层增加模型级 `uvExport` 元数据。每个模型清单包含：

- `version`：裁片配置版本；
- `pieces`：裁片定义；
- `id`、`label`、`order`：稳定标识、中文名称和排版顺序；
- `meshNames` 或稳定几何签名：组成该裁片的网格；
- `duplicateGroup`：需要合并的重复内外面；
- `rotation`、`mirrorX`：工厂图方向修正；
- `zone`：基础外观颜色/花型使用的区域；
- `outputBounds`：仅用于内部排版计算，不作为尺寸声明。

网格编号只作为当前模型的实现细节，不能被通用算法当成语义。后台未来替换模型时，必须同时提供对应的 UV 裁片清单。

### 2. 真实 UV 基础绘制

新增模型感知的基础 UV 烘焙流程，使用裁片清单中的网格 UV 三角形作为裁剪边界：

1. 创建透明或指定背景的 Atlas 画布；
2. 按裁片的 `zone` 选择 body、sleeves、shoulderSide、collar 等颜色；
3. 在每个真实 UV 三角形内绘制模板、色块、渐变或底纹；
4. 只在模型 UV 覆盖范围内写入像素，避免在 Atlas 空白处绘制旧的硬编码形状；
5. 将现有 production decal 图层按原有外侧投影流程叠加。

实时预览和生产导出复用同一份模型感知基础纹理逻辑，避免“页面看起来正确、导出的 PNG 另一个坐标系统”的回归。

### 3. 裁片图重排

完整真实 Atlas 生成后，按裁片清单逐片提取：

1. 合并同一 `duplicateGroup` 的重复面；
2. 将每个裁片的真实 UV 三角形映射到独立的局部画布；
3. 应用清单中的旋转和镜像，使正片、背片、袖片和领片方向稳定；
4. 使用固定留白将局部画布排入 4096×4096 的透明 PNG；
5. 不在图案上添加尺寸或生产线条；
6. 将裁片清单和排版信息写入 `manifest.json`。

裁片 PNG 和原始 Atlas 使用同一个设计快照、同一套图层顺序和同一份源图案，不能分别从 UI 状态重新计算。

### 4. 生产包与 PDF

生产 ZIP 固定包含：

1. `design.json`
2. `uv-atlas.png`
3. `uv-pattern-pieces.png`
4. `uv-reference.pdf`
5. `preview-front.png`
6. `preview-back.png`
7. `manifest.json`

PDF 保持两页：

- 第 1 页：正面和背面预览、设计信息；
- 第 2 页：`uv-pattern-pieces.png` 裁片排版图和简短说明。

原始 `uv-atlas.png` 不从 ZIP 删除，便于 3D 技术人员回贴和排查。

Manifest 新增：

- 两张 PNG 的字节长度和 SHA-256；
- `pieceLayoutVersion`；
- 每个裁片的 id、label、来源网格、重复组、方向和输出顺序；
- 两张 PNG 的覆盖与非空像素校验结果。

## 错误与边界

以下情况不生成裁片图，也不暴露不完整 ZIP：

- 模型缺少 UV；
- 模型没有匹配的裁片清单；
- 裁片包含无法映射的三角形；
- 任一裁片为空或覆盖率低于阈值；
- PNG/PDF 编码失败；
- 设计快照在导出期间发生变化。

错误需要向用户显示明确的中文提示，说明是模型缺少 UV 裁片配置，而不是静默回退成旧硬编码 Atlas。

## 测试与验收

### 单元测试

- 模型 UV 裁片清单校验、重复组去重和方向变换；
- 基础外观只能落在真实 UV 三角形；
- 裁片提取后每个裁片存在非空像素；
- 透明背景、旋转、镜像、留白和排版顺序稳定；
- 清单缺失、UV 缺失、空裁片和映射失败会明确报错。

### 集成测试

- Chelsea 和 FN8788 两个真实 GLB；
- 正面/背面姓名、号码、文字、预设徽章和上传图案；
- 原始 Atlas 可回贴，裁片 PNG 各裁片均有对应图案；
- 重复内外面不会生成重叠的第二张裁片；
- 七文件 ZIP 的 Manifest、PDF 页数和 hash 一致。

### 真实链路

- 在本地页面生成复杂设计并下载 ZIP；
- 打开 `uv-atlas.png` 确认真实 UV 回贴数据；
- 打开 `uv-pattern-pieces.png` 确认裁片方向、留白和图案；
- 使用既有 verifier 校验七文件包；
- 发布前在 Cloudflare 预览地址验证下载入口，不直接用线上版本试错。

## 回退与后续

实现拆成独立提交。若裁片排版或真实模型验证不符合工厂需求，使用保留历史的 `git revert` 回退本功能提交，恢复阶段二的六文件 ZIP；不改写已发布的 `showcase` 历史。

如果工厂最终要求真正的 1:1 纸样、放码或缝份，需要另外提供工厂纸样或由 3D/服装打版人员重新制作模型 UV，本设计不把该范围隐藏在代码里。
