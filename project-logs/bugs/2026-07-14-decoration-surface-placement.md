# 2026-07-14 球衣素材区域贴合错误

## 缺陷

在 Artwork 面板为背面或袖子添加图案、徽章时，素材会悬空在模型前方，红色选择边界也与球衣区域脱离。

## 复现条件

1. 打开独立 3D 定制器。
2. 进入 Artwork，选择 Back。
3. 添加 Roundel Badge 或其他预设素材，再旋转查看模型。

## 影响

预设与上传素材的视觉位置不可信，影响设计确认和展示站演示；设计 JSON 的保存与读取未丢失素材数据。

## 根因

素材使用相机朝向平面并禁用深度检测，导致素材始终覆盖球衣而非贴合区域表面；拖拽坐标没有区分不同区域的局部方向。

## 修复计划

采用区域法线和局部坐标方案，保持现有设计 JSON 兼容。重复点击产生多个素材属于独立的交互体验项，暂不在本次变更中改变。
