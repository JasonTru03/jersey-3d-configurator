# 2026-07-14 球衣素材区域贴合错误

## 缺陷

在 Artwork 面板为背面或袖子添加图案、徽章时，素材会悬空在模型前方，红色选择边界也与球衣区域脱离。

## 复现条件

1. 打开独立 3D 定制器。
2. 进入 Artwork，选择 Back。
3. 添加 Roundel Badge 或其他预设素材，再旋转查看模型。

## 影响

预设与上传素材的视觉位置不可信，影响设计确认和展示站演示；设计 JSON 的保存与读取未丢失素材数据。

## 根因

素材使用固定世界坐标区域锚点，而球衣模型会在载入后按包围盒自动缩放、居中；二者不属于同一坐标依据，导致素材与模型脱离。达到 8 件素材上限时，按钮被静默禁用，造成点击无反应的错觉。

## 修复计划

采用真实球衣网格射线命中和 `DecalGeometry` 投影，保存命中位置与法线并保持现有设计 JSON 兼容；达到素材上限时保留入口并给出明确提示。

## 状态

2026-07-15：固定锚点方案已由真实网格贴花方案替换；定向自动化测试和展示构建待最终批次统一复核。公开展示页视觉验收需在合入 `showcase`、Cloudflare 部署后进行。
