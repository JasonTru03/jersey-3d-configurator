# 2026-07-13 球衣交互编辑器

## 本次目标

实现已确认的首版编辑器：预设素材与本地图片上传，以及素材移动、缩放、旋转和删除。

## 范围与边界

- 全部改动位于独立分支 `codex/interactive-jersey-editor`。
- 本次不包含后端、Shopify 部署、生产素材上传或合并到 `main` 分支。

## 计划改动

- 增加素材预设与可放置区域配置。
- 增加 3D 场景中的可编辑素材图层。
- 增加预设选择、文件上传、区域选择和删除控制。
- 增加单元、组件与浏览器交互验证。

## 自检基线

- 实现前已在隔离 worktree 运行 `npm test`，8 个测试全部通过。

## 已知限制

- 上传图片仅保存在当前浏览器会话。
- 首版使用面向相机的编辑图层，不使用网格投射贴花。

## 实际完成内容

- 增加前胸、后背、左袖、右袖四个放置区域，以及 4 个图案/徽章预设。
- 增加本地 PNG、JPG、WebP、SVG 上传校验（单个文件不超过 5 MB、最多 8 个素材）。
- 选中素材后可直接在 3D 舞台拖动，并可从面板旋转、放大、缩小或删除；选中后会暂时锁定衣服视角，点击空白处可恢复视角控制。
- 预设素材按实际资源地址渲染；修复了图案/徽章被错误当作文本路径加载的问题。
- Shopify 嵌入版复用相同的素材面板，并将可提交配置限制为素材标识、区域和变换参数；不会把本地上传图片的 Data URL 写入订单属性。

## 验证结果

- `npm test`：8 个测试文件、17 个测试全部通过。
- `npm run build`：应用版和 Shopify 嵌入版均构建成功。
- 本地浏览器验收：已确认可进入 Artwork 面板、添加 Golden Stripe，并显示已添加状态和旋转/缩放/删除控制。

## 构建提示

- 两个生产 JavaScript 包仍大于 Vite 默认 500 kB 提示阈值；本次未改变既有打包策略。
