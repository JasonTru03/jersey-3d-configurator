# 2026-07-14 本地设计恢复

## 本次目标

为独立 3D 定制器提供撤销、重做、本地保存、导入恢复和设计确认步骤。

## 修改范围

- 新增版本化 `jersey-design` JSON 设计文件、导入校验和编辑历史模块。
- 为 `useConfigurator` 增加撤销、重做、保存和导入动作。
- 为独立定制器增加编辑工具栏、导入错误提示和设计确认弹层。
- 未修改 Shopify 嵌入版、服务器接口、购物车或支付流程。

## 新增与调整

- `designDocument` 负责深拷贝导出状态，并拒绝无效 JSON、不支持版本、错误产品或缺失设计状态的文件。
- `designHistory` 负责最多 50 个不可变快照；撤销后的新编辑会丢弃旧重做分支。
- 本地 JSON 文件包含上传图片的 Data URL，因此关闭或刷新后重新导入能恢复完整设计。
- 顶部工具栏提供撤销、重做、打开设计、保存设计和确认设计；确认步骤展示选项、素材数量与总价。

## 验证结果

- 自动化测试：`npm test` 成功，13 个测试文件、27 个测试通过。
- 构建：`npm run build` 成功，应用版与 Shopify 嵌入版均完成构建。
