# 2026-07-15 素材编辑器启动回归修复

## 问题

发布素材区域贴合修复后，公开展示站出现空白页。

## 根因

`DecorationEditor.update()` 保留了对已删除 `updateCameraFacing()` 方法的调用。定制器初始化时抛出 `TypeError`，阻断页面渲染。

## 修复

- 移除失效的方法调用。
- 新增空素材集合初始化回归测试，确保更新流程不会调用不存在的相机朝向逻辑。

## 自检

- 素材编辑器测试：7 项通过。
- 完整测试：13 个测试文件、30 项测试通过。
- `npm run build:showcase`：通过。

## 影响与后续

- 仅修复独立定制器的启动崩溃，不改变素材区域贴合数据或交互。
- 推送至 `showcase` 后，需重新打开公开网址验证页面恢复渲染。
