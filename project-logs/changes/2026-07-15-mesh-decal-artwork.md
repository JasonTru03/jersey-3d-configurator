# 2026-07-15 网格贴花重做

## 目标

将独立 3D 定制器 Artwork 的固定场景坐标贴图替换为真实球衣网格投影，修复徽章悬浮和素材上限无提示的问题。

## 新增

- Artwork 保存数据新增 `placement`，记录区域、真实网格命中位置与法线。
- 使用 Three.js `DecalGeometry` 将预设和上传图片投影到球衣网格。
- 旧版设计文件在模型载入后自动获得可保存的网格位置。
- Artwork 面板显示已用槽位数量，并在第九次添加时明确提示上限。

## 变更

- 拖动 Artwork 改为射线命中真实球衣网格；未命中时保留上一次有效位置。
- 变更 Artwork 区域会清空旧区域位置，并在新区域重新投影。

## 验证

- `npm test`：14 个测试文件、36 项测试通过。
- `npm run build:showcase`：通过；保留项目既有的主 bundle 大小告警。
- 公开站视觉验收：待用户确认合入 `showcase` 并部署后执行。

## 遗留

复杂衣物折角可能造成局部贴花拉伸；本期不扩展为 UV 编辑器。
