# 2026-07-29 统一正反面个性化与自动视角

## 目标

- 号码、文字、预设图案和上传图片统一支持球衣正面/背面。
- 选择正面或背面时自动旋转到对应视角，重复聚焦不重置编辑结果。
- 保留各个个性化元素自己的位置、缩放和旋转状态。
- 修复上传图片已添加但 3D 模型不可见的问题。

## 实现范围

- 新增共享的正反面规则与选择器，统一 standalone 和 Shopify 宿主行为。
- 将号码、文字、预设图案、上传图片的区域切换改为串行状态更新，补齐快速操作时的竞态保护。
- 新增正面/背面相机预设，并在临时正反面聚焦后恢复 Orbit、Top、Detail 等当前视图。
- 默认图案投射使用区域锚点与正反面轴向法线，兼容 Chelsea 与 fn8788 两款现有模型。
- 修复 `CanvasTexture` 首次按 `256×256` 分配后又调整 canvas 尺寸导致的 WebGL `GL_INVALID_VALUE`：纹理画布保持固定尺寸，图片自然宽高仅用于贴花几何比例。

## 验证

- 自动化测试：`60` 个测试文件、`713` 项测试全部通过。
- 构建：独立站与 Shopify bundle 均成功；仅保留既有 bundle size / `inlineDynamicImports` 提示。
- 浏览器桌面验收：
  - 号码、文字、预设图案和真实上传 PNG 可切换正反面。
  - 正反面自动旋转正确；重复点击同一面不重置。
  - 上传图片在背面可旋转、缩放，切换其他图案后状态仍保留。
  - 多图案状态相互独立；快速正反切换最终状态正确。
  - Orbit 视图可在临时正反面聚焦后恢复。
- 浏览器移动端验收：`390×844` 下正反面、旋转、缩放、删除和结算控件可用且无遮挡。
- 真实上传 PNG（`571×428`）GPU 验证：
  - 修复前第二次上传为 `571×428`，WebGL error `1281`，纹理不可见。
  - 修复后两次上传均为 `256×256`，WebGL error `0`，正反面均可见。
- 生产静态资源检查：主页、独立站 JS/CSS/GLB、Shopify JS/CSS/GLB 均返回 HTTP `200`。
