# 独立订单后台推进记录

## 用户目标与选择

用户希望顾客加购并付款后，工作人员能在后台按订单找到并下载 design 生产 ZIP。服务器存储验收完成后，用户选择先做方案 1：独立后台；后续稳定后再考虑 Shopify 内嵌后台。

## 已确认边界

- 当前只服务配置的单一 Shopify 店铺。
- 后台使用独立强密码登录，不接 Shopify OAuth。
- 只显示已经由可信 webhook 绑定 Shopify 订单的设计，不显示未付款草稿。
- ZIP 磁盘目录保持私有，工作人员不能依靠哈希文件名手工取件。
- 本轮不连接真实 Shopify、不配置域名/HTTPS、不 push、不部署服务器。

## 本轮结果

- 从稳定服务器分支 `codex/tencent-server-storage` 的 `a35b919` 创建 `codex/admin-order-download`。
- 完成鉴权会话、订单查询、安全流式下载、下载审计和中文后台页面。
- 真实 SQLite 订单与真实文件对象在同一服务器运行时完成登录、列表、下载和审计集成验证。
- 桌面、移动端、登录错误和空状态均完成浏览器验收。
